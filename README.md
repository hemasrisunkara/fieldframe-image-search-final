
# FrameFind

FrameFind is a responsive image-search interface that will let users
explore images by entering topics and viewing image cards in a gallery.

I chose a teal and orange-accented design to give the app a fresh,
nature-inspired identity that stands apart from common purple themes.

I added quick-pick category chips to suggest popular search topics
and an empty-state message to guide first-time visitors.

The results area uses CSS Grid so image cards can adapt to different
screen sizes. Image-search functionality will be added in Part 2.
